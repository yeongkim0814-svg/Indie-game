# 캐릭터 디자인 v1.0 (후드 + 고글)

## 개요
- **기본**: 작은 몸 + 큰 발사기 (계획 유지)
- **신규**: 후드로 머리 덮음, 고글로 얼굴 가림 → 정체성 강화
- **스타일**: 플랫 로우폴리 + 색상 구분, 얼굴 최소화 달성
- **메시**: 삼각 폴리곤 조합 (구/원통 X)

## 신체 구조 (메시 목록)

### 1. 머리 & 후드
- **형태**: 육면체 기반 각진 머리 + 후드 (옆/뒤 흘러내림)
- **구성**: 
  - 머리: 8~12각 박스 (정점 ~20)
  - 후드: 삼각형 4~6장으로 뒤/옆 덮음
- **색상**: 검정 (후드), 살색 (작은 얼굴 영역 — 비노출)
- **노트**: 카메라가 뒤/측면에서만 보므로 얼굴 정면 불필요

### 2. 몸통
- **형태**: 각진 사다리꼴 (어깨 좁음 → 허리 좀 더 좁음)
- **높이**: 키의 30%
- **색상**: 밝은 회색/크림색 (셔츠/슈트)
- **정점**: ~16개 (전/측/후 정의)

### 3. 팔
- **형태**: 각진 원통 (6~8각 프리즘)
- **개수**: 2개, 어깨에서 내려옴
- **색상**: 
  - 팔뚝: 살색
  - 손: 살색 + 손가락 윤곽선 (1px 선)
- **정점**: 각 ~12개

### 4. 다리
- **형태**: 각진 원통 (6각)
- **개수**: 2개, 허리에서 내려옴
- **색상**: 회갈색 (바지)
- **부츠**: 바지 끝에 검정 원형 (발)
- **정점**: 각 ~12개

### 5. 발사기 (오른쪽 어깨 착용)
- **전체 높이**: 몸통의 60~80% (큼)
- **구성**:
  - **포신** (긴 원통): 지름 작음, 길이 길게 (앞으로 향함)
  - **챔버/코일**: 포신 옆 두꺼운 육면체 (전자기 코일 표현)
  - **탄창**: 포신 아래 가는 육면체 (슬러그 저장)
  - **손잡이**: 아래 뒤 손잡이 (사용자 손 거쳐감)
  - **세이프티 핀**: 작은 막대 (방아쇠 위쪽)
- **색상**:
  - 포신/챔버: 진회색 (금속)
  - 코일: 청록색 발광선 (에너지 표현)
  - 손잡이: 검정 (고무)
- **정점**: 총 ~40~50

### 6. 고글 (후드 앞면)
- **형태**: 2개 원형 렌즈 + 금속 테두리 (얼굴 가림)
- **위치**: 머리 후드 앞, 카메라 정면에 약간 비스듬히
- **색상**: 어두운 파랑/보라 (렌즈), 회색 (테두리)
- **크기**: 작음 (캐릭터의 관심을 흐리지 않음)
- **정점**: ~16개

### 7. 벨트 & 클립
- **벨트**: 허리 둘레 얇은 띠 (회색/검정)
- **탄창 클립**: 벨트에 부착한 금속 고리 (발사기에서 탄환 공급)
- **정점**: ~8개

## 카메라 시점
- **기본**: 3인칭 뒤따라가기 (플레이어 뒤 ~3m, 높이 플레이어 눈높이 위)
- **결과**: 후드+고글 측면, 발사기 우측면이 주로 보임 → 얼굴 비노출 ✓

## 애니메이션 상태
- **기본**: 중립 자세 (발사기 앞)
- **도약**: 몸통 아래 압축 → 착지 시 튕김
- **발사 반동**: 몸이 뒤로 밀려남, 발사기 약간 올라갔다 내려옴
- **충전(반동 점프)**: 몸이 옆으로 기울고, 발사기 아래 에너지 수집 모션

## 폴리곤 예산
- **머리+후드**: ~30 정점
- **몸통**: ~16 정점
- **팔×2**: ~24 정점
- **다리×2**: ~24 정점
- **발사기**: ~50 정점
- **고글**: ~16 정점
- **벨트+소품**: ~8 정점
- **합계**: ~168 정점 (초저폴리, 갤럭시 무리 없음)

## 구현 우선순위
1. 기본 몸통 (육면체 조합)
2. 발사기 (가장 시각적 중심)
3. 후드+고글 (캐릭터 정체성)
4. 팔/다리 (마지막)
5. 애니메이션 (별도)
