# Indie Game

모바일 브라우저(갤럭시, 가로) 우선 2D 도트 쿼터뷰 PvE 익스트랙션 슈터. 기획은 `GAME_PLAN.md` 참고.

## 개발
```
npm install
npm run dev          # 로컬 개발 서버 (폰에서 같은 네트워크로 접속 가능)
npm test             # 물리 단위 테스트(Vitest)
npm run build        # 타입체크 + 빌드
npm run check:play   # 헤드리스 Chromium으로 아지트→원정→탈출 시나리오 확인, screenshots/ 생성
```

## 조작 (M1)
| | 터치 | 키보드 |
|---|---|---|
| 이동 | 화면 왼쪽 아무 곳이나 눌러 드래그 (가상 조이스틱) | WASD / 방향키 |
| 사격 | 오른쪽 발사 버튼을 누르고 있기 (가까운 적 자동 조준) | Space / J |

원정 목표: 표본을 주워 동쪽 구역의 초록 원(탈출 지점)에 3초간 머무르면 탈출. 일몰(4분) 전에 나오지 못하거나 죽으면 배낭을 잃습니다(현장 수첩은 남음).

시점: 구역에서는 대각선 쿼터뷰(조이스틱은 화면 기준), 구역 사이 절벽길에서는 횡스크롤로 바뀝니다. 절벽길은 이동 전용이라 사격이 안 되고 생물도 따라오지 못합니다. 절벽길에서 1초 멈추면 카메라가 물러나 풍경을 보여 줍니다.
